About ASTRA

ASTRA — Personal AI & Academic Companion

ASTRA is an intelligent AI-powered desktop assistant designed to simplify everyday tasks and improve academic productivity for college students.

It combines artificial intelligence, natural language processing, desktop automation, voice recognition and persistent academic memory into a unified application.

Core Capabilities

🤖 Intelligent AI conversation

🎙️ Voice recognition and speech synthesis

⚡ Multi-step desktop automation

🧠 Persistent conversation memory

🎓 Personalized academic assistance

📚 Semester and subject management

📝 Assignment and deadline tracking

📖 AI-powered tutoring and revision

🎯 Quiz generation and viva preparation

📄 PDF text extraction and summarization

Technology Stack

Programming Language: Python

Backend Framework: Flask

AI Model: Google Gemini

Database: SQLite

Frontend: HTML, CSS and JavaScript

Speech Recognition: SpeechRecognition

Text-to-Speech: pyttsx3

Desktop Automation: PyAutoGUI

AI Architecture: Agentic Function Calling

Version Control: Git and GitHub

Project Objective

To develop an intelligent personal assistant that integrates academic productivity and desktop automation, allowing students to manage their academic responsibilities and access personalized AI assistance through a single interface.

Version: ASTRA 3.0

Category: Artificial Intelligence and Software Development
