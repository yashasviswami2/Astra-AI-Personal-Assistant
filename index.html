About JARVIS

JARVIS is an intelligent AI assistant developed during the internship to demonstrate natural-language interaction, artificial intelligence, system automation, web search, application launching and voice-based communication.

The system uses a Python Flask backend, Google Gemini API, JavaScript, HTML and CSS to provide an interactive AI-powered user experience.
